# TerpNav
## Project Description
UMD students, staff, or visitors frequently rely on building abbreviations such as IRB, ESJ, CSI, and VMH when navigating the campus. Due to class schedules and daily campus communication, abbreviations are commonly used instead of full building names. However, this can bring inconvenience because most external navigation tools require full building names or formatted addresses. As a result, students may need to search for the complete building name or switch between the UMD campus map and Google Maps to get walking directions. This problem is especially common for incoming freshmen, transfer students, international students, visitors, and campus tour guides because they may not be familiar with campus buildings.

Our proposed system will translate UMD building abbreviations into full building names and structured navigation data. Users can enter a building abbreviation and receive the correct building information with a Google Maps directions link. The goal of this project is to reduce tab switching and repetitive searches, lower stress during short class transition times, and improve navigation efficiency for people who are unfamiliar with the University of Maryland campus.
