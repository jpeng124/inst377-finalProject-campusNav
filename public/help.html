How to Use TerpNav

1. Go to the Home page.

2. Type a UMD building abbreviation, such as ESJ or MCK.

3. Click the search button to view the building information and directions.

4. If an abbreviation is missing, go to the Add New Abbreviation page to submit it.

Frequently Asked Questions

What is a building abbreviation?

A building abbreviation is a short code used to represent a building on campus.

Can I add a new abbreviation?

Yes. Use the Add New Abbreviation page to submit a building abbreviation.
