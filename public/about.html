About TerpNav

The Problem

New students, visitors, and even current UMD students can get confused by campus building abbreviations. Class schedules and campus resources often use short codes like ESJ, MCK, or IRB, but it is not always clear what building they refer to or where they are located. This can make getting around campus stressful, especially when students are trying to find a classroom on time.

The Idea

TerpNav is designed to act like a friendly campus guide. Users can search for a UMD building abbreviation, find the full building name, and get directions quickly. The goal is to make campus navigation easier, faster, and less confusing for everyone.

The Build

This project was built as a simple web application using HTML, CSS, and JavaScript. It includes a search feature for building abbreviations, an About page to explain the project, a Help Center for users, and an Add New Abbreviation page where users can submit missing building information.
